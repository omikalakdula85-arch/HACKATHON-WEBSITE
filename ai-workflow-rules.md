# AI Workflow Strategy for the Hackathon

1. **Never build the whole app at once.** Prompt your AI assistant iteratively.
2. **Step 1:** Build and test the **Core Algorithm** first (backend data structures + mathematical logic). Verify it outputs correct results in isolation.
3. **Step 2:** Build the **API / Integration layer** to connect inputs to the algorithm.
4. **Step 3:** Build the **Frontend UI**, maps, and scenario toggle controls.
5. **Step 4:** Document everything (`README.md`, `AI_USAGE.md`)[span_33](start_span)[span_33](end_span).
6. **Verification:** Always write small test cases or console validators to ensure AI-generated algorithm code is mathematically sound[span_34](start_span)[span_34](end_span).
